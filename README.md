# Shop Game

ファンタジー世界の村のよろず屋から始め、仕入れ、倉庫整理、陳列、販売で資金を稼ぎながら、城下町やほかの地域へ店を広げていく店舗経営シミュレーションゲームです。

## 基本コンセプト

- 店舗経営と、商品の形や倉庫の空間を考える整理パズルを組み合わせます。
- スマートフォンでのプレイを優先し、PC ブラウザでも快適に遊べることを目指します。
- 時間制限やリアルタイム操作を基本とせず、自分のペースで進められる設計です。
- 静的な画面を中心にし、過剰なアニメーションや常時動くキャラクター表現は避けます。

## ゲームサイクル

1. 朝に街の噂や情報を確認し、その日の需要を予測する
2. 仕入れ資金を支払い、ランダムに入荷した商品を倉庫内に整理する
3. 店舗に商品を陳列し、来店した顧客に販売する
4. 売上と利益を確認し、店舗や倉庫を拡張する
5. 翌日の経営に進む

序盤の目標は、村のよろず屋で資金を貯め、城下町に専門店を出すことです。

仕入れでは、支払い後に商品がランダムに入荷し、商品種類・素材・レアリティなどが決まります。入荷した品は倉庫に保管され、何を陳列して売るかはプレイヤーが選びます。仕入れ・抽選と、顧客による購入・販売は別々の仕組みとして扱います。

## 基本操作（予定）

- 倉庫の商品をタップして選択します。
- 選択中の商品をタップすると 90 度回転します。
- 長押ししてドラッグすると移動します。配置可能な場所をプレビューし、配置できない場所には置けないようにします。
- 配置確定前に元の位置へ戻せるようにし、確定後も取り消し操作を用意する予定です。
- スマートフォンでは画面切り替えを基本とし、PC では複数パネルの同時表示を検討します。

## 技術構成

- HTML / CSS / JavaScript（原則 Vanilla JS）
- モバイルファーストのレスポンシブ UI。タッチ・マウス入力に対応
- PC とスマートフォンで共通のゲームロジックとセーブデータ
- ブラウザのゲームデータ保存には IndexedDB を使用する方針
- ソースコードは Git で管理

初期ディレクトリ案や開発時の実装ルールは [`AGENTS.md`](AGENTS.md) を参照してください。

## 開発予定機能

推奨する実装順です。各項目は今後の計画であり、現時点で実装済みとは限りません。

1. 基本画面とモバイルレイアウト
2. 商品データと倉庫の表示
3. 商品の選択・回転・移動、配置可能判定
4. 店舗への陳列
5. 顧客の来店と販売
6. ランダム入荷による仕入れと収支計算
7. セーブ・ロード
8. 噂と需要予測
9. 値引き・追加購入交渉
10. 従業員と複数店舗
