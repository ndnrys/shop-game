# Shop Game

現在のゲームはルートの `index.html` です。画像を使わない画面構成を開発の土台とし、`main` ブランチで実装を進めます。別の試作ゲームや開発用コピーはありません。

## 起動

リポジトリ直下で次を実行し、ブラウザで `http://127.0.0.1:8052/` を開いてください。

```sh
python3 -m http.server 8052 --bind 127.0.0.1
```

JSONをHTTP経由で読み込むため、HTMLファイルを直接開く方法には対応していません。ビルドや外部パッケージは不要です。

## 構成

- `index.html`：ゲームの入口と共通の画面枠。
- `css/game.css`：レイアウト、操作表示、スキンのCSS変数。
- `js/main.js`：一日の流れ、画面描画、操作、JSON読み込み。
- `js/item-core.js`：寸法、配置、回転、近傍の空き位置検索。
- `data/item-catalog.json`：235種のアイテム定義。
- `data/game-settings.json`：倉庫・表示・開発中の仮数値。
- `tests/game.test.mjs`：現行実装のデータ・画面遷移・倉庫操作の確認。
- `docs/`：仕様と設計記録。`docs/data/` の仲間・職業・章・ダンジョン定義は今後の接続用。

## 現在動く機能

朝の報告 → 仕入れ → 仕入れ結果・倉庫整理 → 陳列 → 支援 → 営業 → 翌朝。

- アイテム235種の読み込み、検索、種類・装備枠の絞り込み、詳細表示。
- 複合属性2種を将来候補として通常入荷から除外。
- 仕入れた品を収納・引き取り。同じ画面で倉庫整理。
- 商品をクリックして選択、選択中の商品を再クリックして回転。
- 0.1秒長押しでドラッグ。入荷品も倉庫へ直接ドラッグ可能。
- 重なり・枠外の場合は近くの空きへ補正。置けなければ通知なしで元の状態を維持。倉庫外へのドロップ・キャンセルも元の状態を維持。
- 商品を棚へ補充・倉庫へ返却し、販売して翌日へ進む簡易経済処理。
- 常設6タブ、ページ切替、3種類のスキン、設定JSONの書き出し。

## これから実装する部分

価格・抽選率・能力・耐久の正式な仕様、セーブ／読み込み、仲間の実際の編成・装備・成長・遠征計算、固定費・破産・図鑑・次の街への移動は未完成です。朝の報告・日誌・帰還結果は表示サンプルです。既存画面のボタンや文言だけで実装済みと判断しないでください。

`game-settings.json` の `development` は簡易経済の仮数値です。正式なアイテム価格は `item-catalog.json` の `price: null` として未設定のまま保持しています。

旧版のIndexedDBや旧セーブの読み込み・移行・削除は行いません。現在のゲーム進行は再読み込みで初期状態に戻ります。
