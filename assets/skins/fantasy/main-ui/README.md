# メイン画面UI素材

## 現在の使用素材

2026-11-02にユーザーから提供された1536×1024の透過素材シートを、PNGの矩形領域として切り出しています。再生成や補完は行っていません。

- `interior-male.png` / `interior-female.png`：店主を含む店内。現在は男性版を表示。
- `header.png`：2段のヘッダーと旗。表示文言・数値は含まない。
- `panel.png`：営業パネル。CSSの9スライスで配置。
- `gold-button.png`：文字なしの金色ボタン。HTMLのラベルを重ねる。
- `nav-*.png`：5種類の文字なしメニュー画像。HTMLでメニュー名を表示。
- `scroll-icon.png` / `coins-icon.png`：装飾アイコン。
- `step.png` / `step-active.png`：進捗の菱形。工程数はHTML側で管理。

店員の独立素材は使用していません。現在の実装が使う画像には日本語ラベルは含まれていません。元シートの端にある微細な色縁が残る可能性があり、今回の表示確認はユーザーの指定により省略しています。

以前のZIP由来の画像も同じディレクトリに残っていますが、メイン画面のスタイルは上記の新しい切り出し画像を参照します。

`nav-settings.png` はユーザーが追加提供した透過PNGをそのまま使用しています。設定用の文字記号を置き換えました。
