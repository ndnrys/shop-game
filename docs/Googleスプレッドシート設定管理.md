# Googleスプレッドシートによる設定管理（開発者専用）

## 対象と制限
現在の対象は `data/game-settings.json`、`data/economy.json`、`data/trading.json` の3ファイルです。商品カタログやキャラクター定義などは未対応です。各シートのA列はJSONパス、B列はJSON値（文字列なら `"文字"`、数値なら `123`、配列なら `[1,2]`、未設定は `null`）です。

## 初回セットアップ
1. **非公開の**Googleスプレッドシートを新規作成し、拡張機能 → Apps Scriptを開きます。
2. `tools/google-sheets/Code.gs` をスクリプトに貼り付けます。
3. GitHubで **ndnrys/shop-game の Contents: Read and write のみ**を許可したfine-grained personal access tokenを発行します。公開ゲームやスプレッドシートのセルにはトークンを記入しないでください。
4. Apps Scriptの「プロジェクトの設定 → スクリプト プロパティ」に `GITHUB_TOKEN` を登録します。Apps Scriptの編集権限を他人に渡さないでください。
5. スプレッドシートを再読み込みし、メニュー「ゲーム管理 → GitHubから設定を取得」を実行、初回のGoogle権限を承認します。
6. B列だけを編集し、「ゲーム管理 → 設定を保存・送信」を押して確認します。

## 動作
- 編集だけでは送信しません。保存時に全3シートの行・パス・JSON形式・基本的な型を検証します。
- GitHub側のファイルが前回取得時から変わっている場合、上書きを拒否します。再取得すると未送信の変更は消えるため、必要なら別途控えてください。
- 送信先は `development` 固定です。`main` へのマージ・GitHub Pagesへの公開は行いません。
- GASはゲーム本体から呼び出されません。公開ゲームにはトークンも送信処理もありません。
- **現段階の検証は構造・基本型のみ**です。値の意味的な範囲、ID参照、ゲームバランスの妥当性は保証しません。値を変更した後はゲームのテストが必要です。
- GitHub Contents APIはファイル単位でコミットします。途中で失敗すると一部だけ反映される可能性があります。再取得して状態を確認してください。
- 既存のローカル開発用バランス調整UIは別機能です。この追加では変更・削除していません。
