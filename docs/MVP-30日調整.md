# 攻略率・育成・怪我と30日チュートリアルの調整

2026-11-02。ユーザー指定により、単発の討伐から「攻略率100%でボス出現」へ変更し、30日前後の経営＋支援攻略に調整した。

## 実装した進行

- 最初は攻略率0%。村周辺 → 野営地 → 本拠地前と表示を変えながら、3人で攻略遠征を繰り返す。
- 遠征の成果が良ければ+9%、苦戦しても+3%。上限100%。通常遠征だけでは村クリアにならない。
- 100%で別のボス討伐が出現する。ボスに勝つと村が安全になる。負けても攻略率は100%のままで再挑戦できる。
- 遠征は翌日帰還。支度金は毎回必要で、装備は引き続き部位別・返却不可。
- 帰還時に経験値を獲得し、20ごとにレベルが上がって能力+1。順調な遠征では10、苦戦時も6経験値を得る。
- 遠征で怪我をする場合があり、1〜3日の療養が必要。人物ごとに回復日を持ち、チュートリアルでは全員が回復するまで3人での派遣を待つ。
- 怪我の間も、営業・仕入れ・支援の準備はできる。回復に別のボタン操作は不要で、日付が回復日に達すると派遣可能になる。
- 日誌に攻略率の増加、レベルアップ、負傷、回復、ボスの結果を記録する。

## 100回の通しプレイと別100回の検証

人が100回ブラウザを操作した記録ではなく、実際のゲームの公開操作窓口を使う**自動通しプレイ**で評価した。ゲームのお金・能力・攻略率・抽選結果を途中で書き換えず、新規ゲームの乱数初期値だけを変えている。

- 仕入れ、収納・引き取り、装備支援、陳列、販売、支度金支援、派遣、翌日、回復待ち、ボス、目標額、同行選択・出発まで実行。
- 5日ごとにセーブを検証して再読込し、途中再開でも進めることを確認。
- 4方針を各25回：標準（支度金60）、節約（30）、手厚い支援（90）、商人使い分け（60）。
- 所持品の中で空いている部位や有利な上位装備を支援し、余剰品を棚へ並べる。商売は回復待ちの間も続ける。
- 配置は単純な空き位置探索で、完全な最適化や未来の抽選結果の参照はしない。

| 指標 | 最終調整100回 | 別の乱数で再検証100回 |
| --- | ---: | ---: |
| クリア | 100/100 | 100/100 |
| 平均クリア日 | 29.18日 | 30.37日 |
| 中央値 | 29日 | 30日 |
| 最短〜最長 | 22〜39日 | 21〜44日 |
| 10〜90パーセンタイル | 24〜35日 | 25〜36日 |
| 25〜35日にクリア | 78/100 | 78/100 |
| 平均ボス討伐日 | 26.65日 | 26.96日 |
| 平均で初めて資金目標に達する日 | 27.95日 | 28.82日 |
| 平均遠征回数（ボス含む） | 13.45回 | 13.37回 |
| 平均で怪我による待機があった日数 | 12.20日 | 12.59日 |

200回合計の平均は約29.8日。30日固定の制限や強制待機日数は設けず、攻略・資金・怪我に応じて前後する。回復待ちの日にも経営をするため、何も操作できない時間ではない。

| 方針 | 最終調整の平均 | 再検証の平均 |
| --- | ---: | ---: |
| 標準支援 | 29.68日 | 30.40日 |
| 節約支援 | 28.48日 | 30.00日 |
| 手厚い支援 | 31.88日 | 33.44日 |
| 商人使い分け | 26.68日 | 27.64日 |

支度金を多くすると成果の確率は上がるが、資金目標の達成は遅れる場合がある。装備更新や商人の使い分けにも意味が残る。途中候補も各100回の同一seed比較で調整し、単に日数を引き延ばすより、経営と攻略の両方が条件として働く設定を選んだ。

自動プレイは一定の方針で判断するため、実際の初見プレイヤーの理解時間・操作ミス・独自の方針まで保証するものではない。商売を長く止めたり、装備を更新しなかったりする場合は、目安より時間がかかり得る。手動の使用感は引き続き確認が必要。

## 既存セーブ

保存形式を3へ更新。形式1・2も読み込み、部位別装備・所持金を保持する。旧版でクリア済みなら攻略率100%・クリア済みを維持する。

未クリアの旧データは攻略率0%から新しい進行を開始し、旧版の遠征中データは、元の確率と抽選結果を保持した通常攻略遠征として帰還する。その旧遠征だけは新たな怪我の抽選を行わない。既存の能力値は維持し、追加のレベル・経験値は1・0から開始する。

このデータで30日前後を評価する際は、新規ゲームを使う。途中から移行した所持金や能力は、新規ゲーム100回の条件と異なる。
