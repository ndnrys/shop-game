# MVP実装後の確認事項

2026-11-02。ユーザーの「一旦すべて作りきり、必要な判断は後でまとめて確認する」という指示に基づき、以下を**変更可能な仮仕様**として実装しました。正式決定ではありません。回答は番号ごとに、変更したい点だけでも構いません。

現在のMVPは、村の経営・支援・討伐から、同行者を選んだ出発結果までです。新しい街の本格的な経営は含めていません。

## 1. 仕入れと引き取り

| 項目 | 現在の仮設定 |
| --- | --- |
| 初期所持金 | 400 G。既存のサンプル9品を開業時の無償在庫として使用 |
| 商人 | 武器／防具／道具の3人。毎日、同じ商人へ複数回でも仕入れ可能 |
| 費用・個数 | 武器・防具商人150 G／4品、道具商人120 G／4品 |
| 抽選 | 専門カテゴリ70%、専門外30%。同じ品が重複して出る |
| 道具の専門 | 薬・素材・食料・装飾品。武器と防具以外をまとめている |
| 引取額 | 通常販売価格の10%、専門商品15%。端数切り捨て |
| 支払い | 仕入れ開始時に費用を払い、抽選結果を確定・保存。キャンセル返金なし |
| 入荷置き場 | 各品を自動で空き場所へ収納、または今の商人へ引き取り。自動収納できなければ倉庫画面で整理できる |
| 既存在庫 | 今の商人へ渡せる。棚の商品は先に倉庫へ戻す |
| 取引終了 | 全入荷品を収納または引き取りに振り分けたら終了。取引中の翌日進行・営業・支援は禁止 |

**確認したいこと：** 費用・個数・確率・引取率、商人の利用回数、キャンセル不可と自動収納方式でよいか。道具商人の範囲をどうするか。

## 2. 一般客への販売と収支

- 営業は1日1回。プレイヤーが「店を開いて一般客に販売」を押すと来店・販売結果が確定する。実時間待ちや制限時間はない。
- 外部の冒険者5人が各1品まで購入する。予算・好みに合う陳列品があれば90%で購入し、候補からランダムに選ぶ。価格は商品ごとの固定価格。
- 予算は150〜200 G。個別の予算とカテゴリは `js/data/skins/fantasy/campaign.js` の仮設定。
- 一般客は購入の有無にかかわらず一言話し、経営画面の「今日の来客」と日誌に記録する（ユーザー指定）。今は各客の会話を表示。将来は発言を情勢・噂の情報に結び付け、発言IDとその時点の情報を記録して判断材料にする。需要への効果は未実装。
- 売れ残りは棚に残る。商品を買わない客がいても、同日に再営業して引き直すことはできない。
- 「販売粗利」は売上−売れた商品の仕入原価。「現金収支」は売上＋引取額＋報酬＋手伝い−仕入支出−支度金として別に表示する。
- ガチャの支払額は入荷4品へ均等配賦し、端数を先頭から振り分ける。初期在庫の原価は0。装備の寄贈損や引き取り損益まで含む会計上の純利益は未実装。

**確認したいこと：** まとめて営業を処理する方式、客数・予算・購入率、固定価格でよいか。利益は今の販売粗利＋現金収支で十分か。

## 3. 3人への支援

- リナ・ブラン・ノアを仮の名前とし、能力は12・10・8。
- ユーザー指定で部位別の装備枠に変更。現在の商品に合わせ、武器・盾・胴防具・装飾品の4部位。役割制限なく誰にでも渡せる。薬・食料による追加支援は未実装。
- 装備性能は剣20、斧20、盾16、鎧22、指輪12。装備には消耗・耐久を設けていない。
- 支度金は1人ごとに整数で追加支援できる。渡した時点で所持金から減り、派遣前は本人が保持する。派遣時に全員分を合計して消費する。
- ユーザー指定で、一度渡した装備は返却不可。同じ部位に新しい品を渡すと更新し、旧装備も冒険者の保管品として残す。旧装備の再選択UIは未実装。支度金の返金は今のMVPにはない。

**確認したいこと：** 名前・能力・装備性能、現在の部位区分・誰でも装備可能という簡略化、旧装備の保管後の扱い、支度金の個人別管理と返金なしでよいか。

## 4. 攻略率・成長・怪我（ユーザー指定で変更）

- 3人で通常遠征を繰り返し、攻略率を上げる。順調なら+9%、苦戦しても+3%。100%でボスが出現し、ボス討伐の成功で村が安全になる。
- 派遣条件は装備を1人以上に支援済み、支度金合計30 G以上、全員が怪我から回復済みであること。
- 成果の確率は20%＋能力合計×0.8%＋装備性能合計×0.2%＋支度金合計×0.1%−攻略場所の補正（0〜4%、ボス12%）。下限10%、上限95%。
- 翌日帰還。通常遠征の報酬は順調なら20 G、ボス勝利は250 G。素材報酬はまだない。
- 経験値は順調なら10、苦戦しても6。20経験値でレベルアップし、能力が1上がる。
- 人物ごとに怪我をする可能性があり、回復は1〜3日。回復待ちでも商売と支援準備はできる。
- 10日目から上位の武器・防具・装飾品が仕入れ候補に加わる。
- 死亡は設けず、ボスに負けても攻略率100%と装備は維持する。支度金は各派遣時に消費する。
- 乱数初期値だけを変えた100回と別100回で、クリア日数は平均29.18日／30.37日。数値と方法の詳細は [30日調整記録](MVP-30日調整.md) を参照。

**確認対象：** 攻略率・成長・怪我・約30日という方向性は指定済み。実際に触ったうえで、怪我の頻度や回復日数、支度金と装備の効果などを必要に応じて調整する。

## 5. 日付・立て直し・日誌

- 1年目の春1日から開始し、1季節5日・1年20日。「1日を終えて翌日へ」で進む。
- 営業をしない日も進められる。翌日に帰還判定を行い、その日の収入として報酬を記録する。
- 家賃・生活費などの維持費はない。季節による需要変化は入れていない。
- 仕入れ最低額120 G未満のとき、1日1回「村の手伝い」で80 Gを得られる。援助の借金返済はない。在庫があっても利用できる。
- 日誌には仕入れ・引取・外部客への販売・装備と支度金の支援・派遣・結果・日次収支・出発を自動記録する。
- 日誌は日付別、日付の新しい順。同じ日内は発生順に表示する。羊皮紙風の静的な表示。

**確認したいこと：** 手動で1日を進める方式、維持費なし、立て直し用の手伝いの条件・額、日誌の記録範囲と並びでよいか。

## 6. 村のクリアと出発

| 項目 | 現在の仮設定 |
| --- | --- |
| 必須条件 | リーダー討伐済み＋所持金3500 G以上 |
| 出発時期 | 条件達成後も村で経営を続けられ、任意に出発 |
| チュートリアル案内 | 仕入れ・一般客販売・支援・討伐・目標額をチェック表示。ただし出発の厳密な必須条件は上記2つだけ |
| 開業精算 | 出発前所持金−300 Gを「店舗・移転の開業精算」とし、どれだけ貯めても精算後は300 Gに揃える |
| 同行枠 | 3人のうち0〜3人を自由に選べる |
| 旅費 | 同行者1人50 G。開始資金は300−50×人数。同行なし300 G、全員同行150 G |
| 引き継ぎ | 同行者の能力と装備を出発結果に記録。村の在庫・陳列品・同行しない人物は引き継がない |
| 終点 | 出発結果と次の街の開始資金を表示してMVPクリア。村の操作は以後停止し、日誌閲覧と保存は可能 |
| 新しい土地 | 現地人材の紹介予定を表示。本格的な店舗・クエスト・人材追加は次段階 |

**確認したいこと：** 目標額・基準資金・旅費・同行枠、在庫を引き継がない扱いでよいか。仕入れや販売の体験も出発の必須条件にするか。MVPの終点を出発結果までとしてよいか。

## 実装状況と確認方法

- 計算・抽選・日誌記録・保存は画面から分離し、確定操作を通知して再描画・自動保存する。
- IndexedDBへ自動保存。JSONエクスポート／インポート、最初から開始も用意。
- スキンID・カタログ版・セーブ形式版を検証。取引中・遠征中・出発済みの状態も保存する。
- 既存の別スキンテストは維持。今回の村シナリオはファンタジースキンから渡しており、別スキンへの同等シナリオ追加はそのデータを用意する作業になる。
- 広告・鍛冶・素材報酬・自由編成と同時遠征・従業員・複数店舗は含めていない。
- 詳細な動作確認結果と起動方法は README の現状・動作確認を参照。
