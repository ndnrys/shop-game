# ゲームデータ定義案

このディレクトリは合意した管理項目を保存するためのもの。ゲームはまだ読み込まない。実際のゲーム用データへ反映する際は、既存の職業・アイテム・キャラクター・セーブ移行と合わせて整合性を確認する。

## 職業

- `jobs.json`：基本3職・中位6職・上位12職、計21職のツリーと固定ボーナス。
- `jobs.ja.json`：職業名の日本語辞書。
- `tier` は職業の段階（1〜3）。キャラクターのLvや所属する章とは別。
- `bonuses` はHP・攻撃・防御への固定加算。`equippedAttributeBonus` は装備で持つ各元素属性への加算。装備にない属性は増えず、同じ属性へ職業分を加えるのは1回だけ。
- ボーナスは現在職業の値で置き換える。親職業のボーナスは累積しない。基本職は合計1、中位職は合計3、上位職は合計6。職業由来の属性加算は最大3。
- 装備制限は基本職の `allowedTypes` にまとめ、派生職は `baseJobId` で参照する。転職で装備範囲を狭めたり、新たな装備を追加したりしない。
- 装備範囲は会話で提示した案を保存したもの。実装済みの装備分類とは異なるため、接続時に分類を整理する。
- `classChanges[].requiredLevel` は未決定のため `null`。転職に必要なLvを勝手に決めず、実装時も `null` をLv0や転職可能として扱わない。
- `descriptionKey`・`iconKey` も未設定のため `null`。後で辞書・画像を用意する。
- `status: planned` は未接続の定義であることを示す。

## 接続前の未決定事項

- 転職の解放Lv、転職操作・費用、Lv・能力・装備の引き継ぎ、前の職業へ戻れるか。
- メイスの片手／両手。杖は片手、斧・槍は両手。魔導書・矢は盾枠。弓と矢を併用できる排他判定。
- 既存の剣士・戦士・魔法使いから、新しい3基本職への移行と既存キャラクターへの割り当て。
- 「冒険者」というキャラクター全体の呼び方と、基本職「冒険者」の区別。全体の呼び方は「仲間」案。
- 各キャラクターの加入章と章ごとの同行上限は、職業とは別のデータで管理する。

## キャラクター初期設定案

- `characters.json`：新しい27人の加入章・初期職業・初期Lv・3能力・固有属性。`status: provisional` の暫定合意済みデータで、ゲームには未接続。
- `characters.ja.json`：名前の日本語辞書。
- 配分方針・一覧・未決定事項は [キャラクター初期能力案](../キャラクター初期能力案.md) を参照。職業・装備によるボーナスは初期能力に混ぜない。
- `null` の初期装備・人物紹介・画像は未設定。具体的な装備・画像を勝手に決めない。

## 章管理

- `chapters.json`：村〜終章の9区分。地方、次章、章の敵、クリア条件、同行上限を管理する。ゲームには未接続。
- `chapters.ja.json`：章・地方・魔王軍の討伐対象の名前。章の副題と敵の名前は仮案で、差し替え可能。
- 章の敵を倒すとクリア。敵は `enemy` のID・名前キー・画像キーで管理し、`clearCondition` から参照する。独立した新しいボス戦を追加するものではない。
- 村は既存の森→野営地に対応し、野営地の攻略完了を村の敵の撃破へ接続する案。ほかの章のダンジョンと敵の対応は未設定。敵の能力値や新たな戦闘ルールは作っていない。
- 加入者はキャラクター定義の `joinChapter` と章の `number` を照合して求め、キャラクターIDの一覧を二重管理しない。具体的な加入タイミングは未設定。
- `featuredCharacterIds` は加入前に登場する重要人物。中央第1章でオズワルド、東北第3章でヴェーラ、西南第5章でハキムが登場する仮案。加入は3人とも終章。
- `carryover.memberLimit` はその章をクリアした後に次章へ同行できる人数。候補は直前まで同章で共に戦った仲間。終章は次章がないため `carryover: null`。
- 画像・拠点・所持金・在庫・店舗等の引き継ぎは未設定のため `null`。nullを引き継ぎ可／不可や金額0として暗黙に処理しない。
- 村の所属地方は未設定。中央・東北・西南の具体的な土地の景観と章副題は世界観のたたき台を元にした案。

### 敵と地方名の補足

敵将・魔王は個別能力値を持たず、ダンジョンと同様に繰り返し挑戦し、攻略進度100%で撃破・章クリアとなる。`clearCondition.type: defeatEnemy` はこの進度到達を意味し、別の戦闘処理を要求しない。具体的な敵ごとの必要攻略値・攻略先への接続は未設定。三地方の表示名は中央＝エルディア、東北＝ノルヴァン、西南＝サルディナ。
