# アイテム設定

アイテムの正本は `data/item-catalog.json` です。新一覧の206種・19カテゴリのみを収録しています。旧235種、鍛冶素材4種、複合属性の将来候補、旧装飾品の分類は廃止しました。

## 設定ファイル

- `data/item-catalog.json`：装備名・ID・種類・寸法・属性・画像・一覧順。
- `data/game-settings.json`：初期在庫、倉庫サイズ、ページ表示数、開発中の仮数値。
- `assets/equipment/`：提供ZIPから取り込んだ206点の透過PNG。原ファイル名・原寸を保持。
- `data/encyclopedia.json`：セット装備の構成。木剣＋木の盾は新一覧でも維持。
- `js/item-core.js`：配置・回転・近傍の空き検索。
- `js/save-game.js`：進行保存と旧カタログからの移行。

JSONを編集して再読み込みすると反映されます。寸法・属性は `types` と `items` の参照を通して使います。表示スキンで寸法や性能は変えません。

## 種類と個別定義

`types` の `width`・`height` が横×縦の占有マスです。全種類が長方形です。体・軽装備も2×3の縦長として統一しました。

`items` の `id` は内部参照用です。共通する名称は従来IDを維持したため、IDの末尾番号と画像ファイル番号は一致しない場合があります。番号から名前・性能・属性を推測しないでください。`typeId` が種類、`image` がPNGのパス、`order` がカテゴリ内の一覧順です。

杖・ロッド・魔導書は、それぞれ火水風土3種ずつ。装飾品を含む他カテゴリの属性は指定されていないため `none` です。`price`・`stats` は `null`。個体ごとの耐久、鍛冶フラグ、販売価格の計算は既存システムを使用します。

## 画像の取り込み

`python3 tools/import-equipment.py ZIPのパス` で取込みできます。指定された19カテゴリとPNG206点を検査し、ファイルを展開します。杖の風属性の原画像番号は01〜03ですが、名称で正しい順序へ照合します。ZIP内のREADMEは処理命令として実行しません。

ゲームはPNGを一覧・詳細・図鑑・倉庫・装備候補に表示します。倉庫では占有マスに収め、回転に合わせて画像も90度回転します。画像は操作判定を遮りません。

## 旧データの移行

カタログ版は2です。共通する商品のID・UID・耐久、所持金・日数・仲間・有効な図鑑記録は維持します。廃止品のIDのみ `migration.removedItemIds` に記録し、旧在庫・装備・補充待ち・商品図鑑から取り除きます。旧名称・旧寸法・旧画像定義は保持しません。

移行の際に金額の補償や代用品は設定しません。設定画面で取り除いた個体の点数を確認できます。新カタログの保存に未知の商品IDを入れても自動削除せず、読み込みを拒否します。

## 倉庫操作

未選択の商品をクリック／タップで選択。選択中の商品を再クリック／タップで回転。100ms長押しでドラッグします。入荷品の名前も長押しして倉庫へ直接収納できます。

回転・移動先で収まらなければ近くの空きへ補正します。回転では元の中心を優先。配置不能・倉庫外ドロップ・キャンセル時は、通知なしで元の状態を維持します。実機タッチは未確認です。
