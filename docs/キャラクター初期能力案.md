# キャラクター初期能力案

物語案の27人へ割り振った調整用の初期値。後で調整可能な暫定値としてユーザー合意済み。ゲームには未接続。章番号0＝プロローグ、8＝終章。既存のリナ・ブラン・ノアはこの新しい名簿へ含めない。

職業・装備ボーナスを含まない本人の初期値を記載する。Lv1の基準を9点、1Lvあたり3点とし、固有属性の合計も同じ予算に含めた `HP＋攻撃＋防御＋固有属性合計＝9＋3×(Lv−1)` を配分の目安にする。固有属性と3能力が実戦上同等という意味ではなく、同章の新規加入者間の差を抑えるための仮予算。固有属性は現在の合意では経験値ボーナスに影響し、直接の攻略進度ボーナスにはならない。

加入Lvは村1、以後の章で2ずつ増やす仮案。同行する仲間のLv・育成・装備はそのまま引き継ぎ、新章の加入者の値で上書きしない。通常章の新規加入者は基本職、終章の団長は最上位職で加入。転職の必要Lvはこの表では決めない。

## 初期設定の未決定箇所

- 初期装備・人物紹介・画像は未設定。`initialEquipment: null` は未設定の意味であり、「装備なし」と確定したものではない。
- 初期固有属性は装備の有無にかかわらず本人が持つ。職業の `equippedAttributeBonus` は装備にある属性へ加算する既存合意を維持し、固有属性だけを理由に二重加算しない。
- 村の男女構成はカイル男・ガレス男・ミラ女。
- 団長は中央オズワルド（重騎士）、東北ヴェーラ（狙撃手）、西南ハキム（大魔術師）。終章に加入し、それ以前の地方で登場する。初登場の正確な章と登場イベントは未設定。
- 章ごとの実戦難易度、必要経験値、初期装備を合わせた数値調整は別途必要。

## 章ごとの同行ルールの合意

各章は新規3人＋直前の章の参加メンバーから選んだ同行者で構成する。同行上限は第1章1人、第2章2人、第3章3人、第4章4人、第5章5人、第6章6人、第7章6人、終章6人。終章の新規3人は既出の団長。終盤の最大人数は9人・3パーティ。選ばなかった仲間は各地の防衛・復興のために残る案。加入時の設定と章の同行上限は別データで管理する。
