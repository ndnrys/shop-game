# 世界観・章構成メモ

更新日：2026-11-03

会話で決めた世界観と章構成の記録。ゲームへの実装とは分けて管理する。

## 世界観の合意

- 舞台は一つの大陸。
- 大陸の北東に城がある。最初の指定では「魔法城」、以降も終章の舞台としてこの呼称を仮置きしている。城の正式名称は未確定。
- 西南地方・中央地方・東北地方の三地方で魔王軍と戦っている。
- 最後に加入する3人は、三地方それぞれの団長に相当する重要人物。
- この3人とはそれぞれの地方の章で既に出会っており、終章でまとめて仲間になる。終章での加入が初対面ではない。
- 団長3人は最上位職で加入する。
- ゲームの主人公は店を経営し、仲間への装備・支度金などの支援で攻略を進める。

## 次に整理する章管理項目

以下は項目案であり、章JSONの確定仕様ではない。

- 章ID・章番号・名前／説明の翻訳キー。
- 地方ID、拠点・地図・背景の参照。
- 加入するキャラクターIDと加入タイミング。
- 攻略するダンジョンIDと解放順序。
- 章クリア条件、次章への接続。
- 次章へ連れていける人数、候補者の範囲。
- 店舗・所持金・倉庫・陳列・同行者の装備等の引き継ぎルール。
- 初対面・再会・団長登場などのイベント。必要になったものから管理する。

レアリティの数値範囲、シリーズの合わせ買い、弓・矢・魔導書の装備整合性、転職Lvなどの未決定事項は、章管理を決めても別途整理する。

## 章ごとの魔王軍の討伐対象（追加合意）

- 各章に魔王軍の討伐対象を設定し、名前と画像を管理する。
- その対象を倒すと章クリアになる。
- 管理構造案は `enemy: { nameKey, imageKey }`。表示名は翻訳キーで管理する。敵の名前は下記に設定済み。画像は未設定。
- 対象と攻略先の対応、撃破状態をどの攻略完了から確定するかは章の項目整理時に決める。従来の「必要攻略値到達で攻略先クリア」と整合させ、独立した別ボス戦を勝手に追加しない。

## 敵将・魔王の攻略方法（確定事項の補足）

- 敵将・魔王に個別のHP・攻撃・防御などの能力値は設定しない。
- ダンジョンと同じく繰り返し挑戦して攻略進度を蓄積し、100%到達で撃破・章クリアとする。
- 100%は必要攻略値への到達を意味する表示。内部の必要攻略値を全敵一律100へ変更する指示ではない。具体的な必要攻略値は別途設定する。
- 敵用のダメージ計算や、進度到達後の追加ボス戦は設けない。敵の名前・画像は攻略対象の演出と識別に使う。
