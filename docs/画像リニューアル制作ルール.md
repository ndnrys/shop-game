# 画像リニューアル制作ルール

## 対象

- 仲間27人：通常・派遣決定・負傷療養の透過PNGを各1枚。顔立ちを全員描き分け、同一人物の3表情は顔・服装・構図を揃える。
- 死亡時：通常画像をCSSのgrayscaleで表示。専用の死亡画像は作らない。
- アイテム210点：既存の縦横比・ゲーム上の寸法・ID・価格・能力値を維持して描き直す。

## 最新のユーザー指定

- 服・装備の継ぎ接ぎ、補修布、穴を塞ぐ縫い跡は不可。カイルも緑の上着を継ぎ接ぎなしにする。
- 人物設定に合った汚れ・煤・土埃は可。
- 絆創膏、粘着テープなど現代的な医療用品は不可。療養は疲れた目や痛みに耐える表情で示す。
- 槍10種は1×7マス。垂直に穂先を上、石突きを下へ向け、長い柄を描く。斜め構図で枠内の絵が小さくならないようにする。
- 剣・斧など刃物は刃こぼれ不可。切れる、連続した刃先を描く。
- 商品名に「錆びた」などの状態指定がある場合は、その状態を描く。状態名のない商品に勝手な錆・欠けを追加しない。
- 成人女性の一部は人物像に合わせて大人の色気を取り入れる。胸元の開いた衣装、露出を抑えた服越しの豊かな体つきなど、表現を描き分ける。
- 全員の立ち絵は通常・派遣・療養を通じてキャンバスサイズ、頭の位置、表示の高さを揃える。
- 背景は実際のアルファ透過。人物の外側にグラデーション・光彩・色付きの背景を残さない。
- 暖かな手描きファンタジーのタッチ。画像内の文字・ロゴ・透かしは不可。
- 画像ごとのユーザー確認・承認は不要。生成・内部確認・組み込みまで続行する。

初回の人物設定中にある「継ぎはぎ」「補修跡」より、上記の最新指定を優先する。

## 生成と保存

組み込みのImageGenを使用。人物の共通プロンプトと個別設定は `assets/characters/warm/production.json`、商品ごとの元画像・寸法・出力先は `assets/equipment/warm/production.json` に保持する。

人物差分は通常画像を参照して顔・髪・衣装・構図を維持し、派遣では決意のある表情、療養では疲れや痛みをこらえる表情へ変更する。背景・光彩・グラデーションは取り除き、人物外側をアルファ透過にする。

商品共通プロンプトは、暖かく落ち着いた水彩とガッシュ、繊細な茶色の輪郭、素材がわかる木・革・布・金属、商品名と説明に合う単品の全体像。商品ごとの元画像の縦横比を指定し、文字・背景・光彩・影・人物を含めない。刃は連続した使用可能な刃先とし、錆は名称で指定された商品に付ける。

完成PNGは人物を `assets/characters/warm/`、派遣を同 `battle/`、療養を同 `resting/`、商品を `assets/equipment/warm/` に保存する。

## 組み込み確認

- 仲間27人の3表情81枚、商品210点をゲームのJSONから参照。
- 立ち絵81枚は1024×1536、全商品は元PNGと同じ寸法。全ファイルはRGBAの透過PNG。
- 全画像を異なる背景色へ重ねて一覧確認。半透明の宝石や輪郭は目視確認。
- 390×844と360×640のスマートフォン幅で全画面・在庫あり画面の表示検証が成功。
- 81枚の読み込み、状態による表情切替、死亡時のグレー表示、旧帰還報告の画像参照をブラウザ検証。
- 画像以外の商品・人物定義が変更されていないことを比較確認。
- `node --test tests/game.test.mjs` は実行環境にNode.jsがなく実行できなかった。実機タッチは未検証。

## 支援・装備・育成の立ち絵表示

支援と編成は既存の3表情を顔のアップで表示する。装備・育成の背景用に通常絵と同じ顔・衣装の全身画像を27人分追加し、`assets/characters/warm/full/` に保存。1024×1536の透過PNGで、画面では22%の濃さで表示する。背景はクリックやドラッグを受け取らず、死亡時はグレー表示する。全身生成の共通指示は人物の `production.json` に記録する。
