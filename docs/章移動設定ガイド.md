# 章移動設定

現行の実装は村（chapter 0）から第1章（chapter 1）への移動です。`docs/data/chapters.json` の村→第1章・同行上限1人・村の野営地と敵の対応、辞書の章名・敵名を現行設定へ採用しました。設計ファイル全体を読み込む実装ではありません。

`data/game-settings.json` の `chapterProgression.prologue` を変更します。

| キー | 用途 |
| --- | --- |
| `name` / `nextName` | 村と移動先の表示名 |
| `enemyName` | 村の攻略対象の表示名 |
| `clearDungeonId` | 討伐完了に対応する遠征先ID（camp） |
| `nextChapter` | 移動先番号。現在は1のみ対応 |
| `memberLimit` | 同行人数。現在は1のみ対応 |

出発条件は朝・野営地クリア・借入加算込みの必要資金確保・未払いなし・未整理入荷なし・遠征なし・存命の同行者選択。療養中の同行は可能ですが、復帰日まで派遣できません。出発処理でも条件を再確認します。必要資金は保持条件で、移動費としては差し引きません。

第1章に加入する人は `data/characters.json` の `joinChapter: 1` を参照。同行者と加入者だけを使用可能にし、残る仲間の装備と個人状態は保存し続けます。再加入のルールは未設定です。店舗と商品等はREADMEに記載した範囲で維持します。保存構造は既存のchapter・availableCharacterIds・parties等を共用し、移動前の選択は保存しません。再読み込み時は確定した章の経営画面へ戻ります。

遠征先は同JSONの `dungeons`。第1章の仮設定は以下です。

| ID | 必要攻略値 | 凶悪度 | 前提 |
| --- | ---: | ---: | --- |
| `eldia_road` | 180 | 5 | なし |
| `velk_blockade` | 300 | 6 | `eldia_road`クリア |

新規3人の本人攻撃合計12に対して、成長・負傷を除く単純計算で15回＋25回の設定です。同行者・成長・負傷・経済を含む実際の攻略日数は未測定。属性の正式値や装備能力・価格は追加していません。第2章以降への移動は未接続です。

ブラウザ検証は `tests/chapter-ui.html?width=360&height=640`、390×844、1280×900。既存のdurability・characters・equipment・economyのブラウザテストも同3サイズで確認。Node.jsテストは環境に実行ファイルがないため未実行、実機タッチは未確認です。
