# 現在のデータと接続状況

ゲームの入口はルートの `index.html` です。

| ファイル | 用途 | 読み込み |
| --- | --- | --- |
| `data/item-catalog.json` | アイテム235種・種類・寸法・属性・素材用途 | `js/main.js` |
| `data/game-settings.json` | 倉庫・ページ表示・開発中の仮数値 | `js/main.js` |
| `docs/data/*.json` | 仲間・職業・章・ダンジョンなど今後接続する設計定義 | 現在はゲームから読み込まない |

旧版の `js/data/skins/fantasy/*.json` は、今後の仕様を失わないよう `docs/data/` に集約しました。装備種類の正式な寸法・属性の正本は `data/item-catalog.json` です。旧 `equipmentTypes.json` の分類は設計記録です。

旧画像・旧CSS・旧ゲームシステム・それらだけを参照したテストとシミュレーション・独立した試作HTMLは削除しました。必要な場合はGit履歴から取り出します。

詳細は [アイテム設定ガイド](アイテム設定ガイド.md) を参照してください。
