# 現在のデータと接続状況

ゲームの入口はルートの `index.html` です。

| ファイル | 用途 | 読み込み |
| --- | --- | --- |
| `data/item-catalog.json` | アイテム206種・19カテゴリ・寸法・属性・PNG参照 | `js/main.js` |
| `data/game-settings.json` | 倉庫・ページ表示・開発中の仮数値 | `js/main.js` |
| `data/economy.json` | 章別の固定費・棚増設費と共通のLvあたり治療単価。調整用仮値 | `js/main.js`で読み込み、`js/economy.js`で計算。nullは設定エラー |
| `data/characters.json` | 27人の初期設定。村の3人の名前・職業・Lv・能力・固有属性の表示 | `js/main.js` |
| `docs/data/*.json` | 職業・章・ダンジョンなど設計定義と仲間設定の旧記録 | 現在はゲームから読み込まない |

旧版の `js/data/skins/fantasy/*.json` は、今後の仕様を失わないよう `docs/data/` に集約しました。装備種類の正式な寸法・属性の正本は `data/item-catalog.json` です。旧 `equipmentTypes.json` は削除し、新一覧へ一本化しました。

旧画像・旧CSS・旧ゲームシステム・それらだけを参照したテストとシミュレーション・独立した試作HTMLは削除しました。必要な場合はGit履歴から取り出します。

詳細は [アイテム設定ガイド](アイテム設定ガイド.md) を参照してください。

固定費の合意内容・設定方法・未決定事項は [固定費・治療費仕様](固定費・治療費仕様.md) を参照してください。固定費精算・棚増設・保存された負傷状態の治療と自然回復を接続済み。負傷発生と破産救済は接続済み。成長は遠征に接続済み。章進行・広告SDKは未接続です。

キャラクター初期設定の現行正本は `data/characters.json`。`docs/data/characters.json` は元の設計記録です。初期装備・紹介文は未設定を維持し、画像ファイル名は参照情報のみです。後続章の加入処理は未接続です。

装備個体の耐久・鍛冶状態は商品定義と分離し、進行セーブversion 2へ保存します。`js/equipment-core.js`が計算、`js/equipment-ui.js`が装備・遠征の接続、`js/save-game.js`が保存と移行を担当します。人物の初期能力は装備画面にも表示します。装備による能力補正と遠征の戦闘・報酬計算は未接続です。

## 売買・棚効果

`data/trading.json` の棚ボーナス・顧客購入傾向・章別所持金／来店者数／出現重み・噂倍率／期間を現行mainへ接続。セットは既存の `data/encyclopedia.json` を共用。顧客と章の数値は開発用仮設定、噂の発生イベントは未接続。[設定ガイド](売買・棚効果設定ガイド.md)参照。

### 開発者用バランス調整

`/dev/balance.html` と `js/balance.js` は既存の経済・売買・救済JSONを共有します。ローカルホストかつゲームURLの `?dev=balance` でのみ調整を使用。追加・除外項目、保存形式、反映タイミングはREADMEの「開発者用バランス調整」を参照してください。未接続の戦闘・成長値は追加していません。

## 追加仕様・第1項目：ダンジョン攻略

`game-settings.json` の `dungeons` が現行の遠征先設定です。`docs/data/dungeons.json` は読み込まず、攻略値60/140・凶悪度3/5を現行設定へ採用しました。攻撃合算・装備の明示属性値によるボーナス・翌朝の進度加算・クリアと前提解放・進度保存を接続。`js/equipment-ui.js` が計算と画面を担当します。旧遠征には攻略実績を推測して追加しません。

属性値はカタログの任意の `attributes` オブジェクト。現行品の未確定数値は追加していません。推奨属性・係数の仮値と29遠征の確認範囲はREADMEの「ダンジョン攻略」を参照。怪我・死亡は以下の第2項目で接続済み。育成は第3項目で接続済み。章クリア判定は未接続です。

## 追加仕様・第2項目：冒険者パラメータ

`js/adventurer-core.js` は凶悪度・防御・HPからリスクと復帰期間を計算。`game-settings.json` の `adventurers` が仮値と職業別の許可type IDの正本。出発時のhealthを保存し、帰還時に `economyState.companions` へ反映。手動装備・自動再装備の職業制限、療養・死亡表示を接続。旧職業の能力加算・転職・未確定装備能力は接続しません。式と保存互換は[固定費・治療費仕様](固定費・治療費仕様.md)を参照。

## 追加仕様・第3項目：冒険者の育成

`adventurers.growth` に4方針と必要経験値を集約。帰還時の実進度÷参加人数を切り捨てて個人経験値を付与し、レベルアップごとに3ポイントを自動配分する。`AdventurerCore` は成長・経験値・能力合算、`equipment-ui.js` はキャラクターの育成画面と帰還連携、既存の人物経済状態が保存先。過去の成長を再配分しない。旧セーブのLvから成長値を推測しない。[冒険者育成設定ガイド](冒険者育成設定ガイド.md)を参照。

## 追加仕様・第4項目：装備操作

装備タップ選択→対応枠タップと、100ms長押しドラッグ、装備枠から倉庫への取り外しを接続。入力処理は `js/equipment-input.js`、共通確定処理は `equipment-ui.js`。属性値・属性合算・推奨表示は既存機能を共用。ユーザー訂正により5部位を維持し、頭装備は削除しない。[装備操作仕様](装備操作仕様.md)を参照。

## 追加仕様・第5項目：操作UI

仕入れ・支度金・育成方針は既存のボタン方式を共用。仕入れ主要ボタンと支度金の加算・取消を44×44px以上へ拡大し、増減・加算・取消に読み上げ用の操作名を追加。育成方針は既存の高さ72pxを維持。計算・設定値・セーブ構造は変更しない。スマホ幅のみを検証対象とする。

## 追加仕様・第6項目：倉庫

新規5×5、旧セーブ8×8維持、5→6→7→8の有料拡張を接続。正本は `game-settings.json` の `warehouse` と `warehouseExpansion`、進行寸法は保存対象の `warehouseSize`。大工の住人画面、配置・装備交換の共通寸法、仕入れの残容量表示を接続。仕入れ・寄付・新規初期品は回転込みで倉庫寸法に収まるものに限定し、初期槍は対象外。旧セーブの所持品は維持。[倉庫拡張設定ガイド](倉庫拡張設定ガイド.md)を参照。
