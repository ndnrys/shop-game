# 装備操作仕様

追加仕様の部位数はユーザーの訂正に従い、武器・盾・頭・胴・装飾品の5部位とする。30種の頭装備を削除・移動しない。商品ID・在庫UID・保存versionを変更しない。

## タップとドラッグ

キャラをタップして装備画面を開く。倉庫候補にはその職業で装備できる商品を部位をまたいで2点ずつ表示する。

- 商品タップで選択。同じ商品を再タップで解除。選択中は対応部位を強調し「ここに装備」と表示する。
- 選択中の商品の対応枠タップで交換を確定する。不適合枠では変更しない。
- 商品の100ms長押しでドラッグ。対応枠へ離すと装備する。Mouse/TouchともPointer Eventsを使用する。
- 装備済みの枠を100ms長押しし、倉庫候補欄へ離すと取り外す。「外す」ボタンも共用する。
- 枠だけのタップでは、詳細操作の対象部位を変更する。対象部位の自動再装備設定・取り外しボタンを表示する。

倉庫へ戻せる位置を計算してから在庫と装備を更新する。UID・耐久・鍛冶状態は維持。倉庫不足、不適合、枠外、Pointer Cancel、ウィンドウ失焦、Escapeでは在庫・装備を変更しない。UIからの失敗にアラートは出さない。ドラッグ中のプレビュー・タップ選択は保存状態に含めない。

人物変更・画面移動・育成切替・一覧ページ変更・セーブ読み込み・初期化では進行中ドラッグを解除する。人物変更・画面移動・育成切替・セーブ読み込み・初期化ではタップ選択も解除する。ドラッグ後の合成クリックは400ms抑制する。遠征中の変更、死亡者への新規装備、職業不適合品の装備は既存のルールで拒否する。死亡者の取り外しは許可する。

## 実装・属性・検証

確定処理と画面は `js/equipment-ui.js`、Pointer Events・一時プレビューは `js/equipment-input.js`。クリックとドラッグは同じ交換処理を使う。既存の `attributes`・パーティ装備属性合算・推奨属性表示を再利用する。画像名・elementから未設定の数値を推測しない。

Nodeテストはタップ選択の未確定状態、交換と耐久維持、マウス／タッチ相当の長押し、倉庫へ取り外し、誤部位・枠外・キャンセル、人物変更時の解除、職業・遠征ロック、倉庫不足時の原状維持を確認する。

`tests/equipment-ui.html` はスマホ幅360×640・390×844で各24項目を確認。DOM上のPointer Eventsでタッチ相当のドラッグとクリックを実行し、画面収まりも確認する。実機タッチは未確認。PC画面テストはユーザー指示で省略。
